# Lead Sourcing And Tracker

This is the operating workflow for building the first 100-project lead list for Singularity.

## Lead List Objective

Build a qualified list of Solana and crypto projects that are likely to need contributor funding, launch support, or a mission-native treasury system.

The goal is not a large CRM. The goal is to find 30-50 founders worth contacting and 10 worth speaking with.

## Source Buckets

### X Search

Search for founders and projects using combinations of:

- `solana building`
- `solana project launch`
- `solana demo`
- `solana bounty`
- `solana grant`
- `solana hackathon`
- `looking for contributors solana`
- `hiring contributors crypto`
- `building on solana`
- `devnet launch solana`
- `mainnet soon solana`
- `grant application solana`
- `open source solana`

Prioritize posts where the founder is explaining progress, asking for help, or recruiting contributors.

### X Reply Mining

Use high-signal source posts from:

- Solana ecosystem accounts.
- Hackathon announcement threads.
- Demo day threads.
- Grant program announcements.
- Builder callouts.
- Founder launch posts.
- Investor or scout posts asking what people are building.

The existing outreach agent can help inspect replies and draft context, but the first campaign should remain founder-led and high-touch.

### Ecosystem Programs

Pull leads from:

- Solana hackathons and demo days.
- Superteam projects, bounties, and earn listings.
- Solana Foundation grant announcements.
- Colosseum cohorts and public submissions.
- Accelerators, demo days, and founder showcases.
- Protocol-specific ecosystem grant pages.

### Community Channels

Use communities where founders already talk about work:

- Solana and Superteam Discords.
- Protocol ecosystem Discords.
- Builder Telegram groups.
- Hackathon channels.
- Devrel office hours.
- Local crypto founder groups.

Do not spam these channels. Use them to identify founders, then reach out personally with context.

### Warm Intro Sources

Ask these people for 2-3 founder referrals:

- Crypto angels.
- Ecosystem scouts.
- Developer advocates.
- Grant reviewers.
- Hackathon judges.
- Accelerator operators.
- Founder friends.

Intro ask:

> Who is building something real on Solana, has contributors or ecosystem work to fund, and would benefit from a more public funding flow?

Track each project with these fields:

| Field | Description |
| --- | --- |
| Project | Project name. |

| Funding pain | Contributor, bounty, audit, infra, content, growth, grant, launch, unknown. |
| Proof of work | Demo, repo, product, waitlist, community, shipped, none. |
| Community surface | X audience, Discord, Telegram, GitHub, newsletter, none. |
| Score | 0-18 using the ICP rubric. |
| Message angle | Contributor funding, community-aligned raise, or mission launch. |
| Contact status | Not contacted, contacted, replied, call booked, rejected, design partner. |
| Next action | Specific next step and date. |
| Notes | Context that should make outreach feel personal. |

## Daily Sourcing Routine

Run this for 7 days.

1. Add 15-20 raw leads from X and ecosystem sources.
2. Score each lead using the ICP rubric.
3. Keep only leads scoring 13 or higher, unless there is a strong warm intro.
4. Write one context note per qualified lead.
5. Contact 5-8 founders per day.
6. Ask every founder who replies for one referral.

## Prioritization Rules

Contact first:

- Founders who recently posted about a launch, demo, grant, bounty, or hiring need.
- Projects with obvious funded work to be done in the next 30-60 days.
- Teams with enough audience to co-market.
- Warm intros from trusted crypto operators.

Deprioritize:

- Projects whose only visible goal is liquidity.
- Teams with no founder identity or trust surface.
- Projects that require a long technical explanation before the mission makes sense.
- Any lead where the outreach would have to be generic.
